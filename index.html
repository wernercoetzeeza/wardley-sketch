Aboutv0.0.0

Wardley Sketch

A mobile-first sketchpad for Wardley Maps. Designed for capturing ideas while reading, travelling or discussing strategy away from your desk.

Installable

This is a Progressive Web App — install it for a full-screen, offline-ready experience with no browser chrome.

iPhone/iPad: Share → Add to Home Screen
Android/desktop: tap the install icon in the address bar

Wardley Mapping
